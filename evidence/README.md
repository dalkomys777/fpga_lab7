# LAB7 pre-lab evidence

This directory contains the source screenshots and reproducible simulation artifacts used in the LAB7 pre-lab report.

- `user_captures/`: VS Code source, build, PASS, and waveform screenshots supplied by the student.
- `prelab/spi_slave/`: SPI slave VCD.
- `prelab/spi_master/`: SPI master VCD.
- `prelab/spi_fpga_link/`: integrated FPGA-to-FPGA VCD.
- `prelab/*_simulation.txt`: console logs captured while reproducing each self-checking simulation.

Vivado implementation screenshots, XDC files, hardware videos, and oscilloscope results are intentionally excluded from this pre-lab evidence set. They belong in the post-lab report after the physical experiment.
